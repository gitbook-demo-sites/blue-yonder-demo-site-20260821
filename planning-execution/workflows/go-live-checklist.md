# Go-live checklist

A launch checklist for rolling out a new planning or execution workflow.

{% hint style="info" icon="gitbook-assistant" %}
Use the Assistant on this page to ask how this topic affects planners, operators, developers, and partners.
{% endhint %}

## What to document

* Confirm data sources, roles, and approval gates.
* Publish role-based training paths.
* Prepare support, release notes, and rollback guidance.

{% tabs %}
